Alles über Musik.

Die komplette Anleitung: Server einrichten, Apps verbinden, Musik reinbringen, andere Plattformen nutzen, teilen, Equalizer, Visualizer und was tun, wenn etwas hakt.

01Überblick

Musik besteht aus drei Teilen:

  • Server: ein kleines Programm (Rust), das deine Musikdateien einliest, sich merkt, was du hörst, und alles an die Apps streamt. Er läuft am besten als Container in Proxmox, geht aber auch auf Debian, Ubuntu, Docker, Windows und einem Raspberry Pi.
  • Apps: Android, Windows und Linux. Dazu der Webplayer, der im Browser direkt vom Server kommt.
  • Der Mix: ein Empfehlungs-Algorithmus auf deinem Server. Er lernt aus dem, was du ganz hörst, überspringst und likest.

Deine Dateien bleiben auf deinem Server. Andere Plattformen (YouTube, Spotify, SoundCloud) kommen nur dazu, wenn du sie einschaltest.

02Schnellstart

  1. Server installieren, am einfachsten in Proxmox (siehe Installation). Am Ende steht eine Adresse wie http://192.168.1.50:8484.
  2. Die Adresse im Browser öffnen oder in der App eintragen. Beim ersten Start legst du deinen Account an, der erste Account ist Admin.
  3. Die App fragt, woher Songs kommen dürfen. „Lokal“ reicht für den Anfang.
  4. Musik in den Musikordner legen oder in der App über Einstellungen → Musik hochladen hochladen.
  5. Auf Start tippen und „Mix für dich“ abspielen.

Den Webplayer erreichst du auch über den Knopf Webplayer oben rechts auf der Startseite. Er merkt sich deine Server-Adresse.

03Server installieren

Proxmox (empfohlen)

In Proxmox die Node anklicken, Shell öffnen und einfügen:

bash -c "$(curl -fsSL https://raw.githubusercontent.com/Labtoso/Musik/main/deploy/proxmox.sh)"

Das Skript legt einen Debian-12-Container an (2 Kerne, 512 MB RAM, 8 GB), installiert den Server und zeigt am Ende die Adresse. Es fragt einmal, ob du Musik mit oder ohne Tailscale willst (siehe Unterwegs).

Optionen setzt du vor den Befehl, zum Beispiel MUSIC_HOST_DIR=/mnt/nas/musik bash -c "…":

OptionBedeutung
MUSIC_HOST_DIROrdner auf dem Proxmox-Host mit deiner Musik. Wird nur lesend in den Container eingebunden (/srv/musik/library).
CTIDNummer des Containers, sonst die nächste freie.
CT_CORES, CT_RAM, CT_DISKKerne, RAM in MB, Platte in GB (Standard 2 / 512 / 8).
CT_BRIDGE, CT_STORAGENetzwerk-Bridge (Standard vmbr0) und Speicher für den Container.
TAILSCALE=1 / TAILSCALE=0Tailscale direkt an oder aus, ohne Frage.
TS_AUTHKEYTailscale-Schlüssel, damit du keinen Link öffnen musst.

Update: denselben Befehl noch einmal ausführen. Das Skript findet den Container und aktualisiert ihn. Daten, Playlists und Likes bleiben.

Debian / Ubuntu

curl -fsSL https://raw.githubusercontent.com/Labtoso/Musik/main/deploy/install.sh | sudo bash

Installiert den Dienst musik (systemd). Optionen hinter bash -s --: --music /pfad, --port 8484, --tailscale, --no-tailscale, --ts-authkey …. Update später mit musik-update.

Docker

git clone https://github.com/Labtoso/Musik.git && cd Musik && docker compose up -d --build

Musik kommt in den Ordner music/ neben der docker-compose.yml, die Daten liegen in data/. Port 8484.

Windows

musik-server-windows-x64.exe von der Release-Seite laden und starten. Er nimmt deinen Musik-Ordner. Andere Ordner trägst du in eine .env neben der exe ein: MUSIC_DIRS=D:\Musik.

Einstellungen des Servers

Der Server liest Umgebungsvariablen oder eine .env-Datei. Im Proxmox-Container und unter Debian liegt sie in /etc/musik.env. Nach einer Änderung: systemctl restart musik.

VariableStandardBedeutung
PORT8484Port des Servers
HOST0.0.0.0Adresse, auf der er lauscht
MUSIC_DIRSMusik-OrdnerOrdner mit Songs, mehrere mit : (Windows ;) trennen
DATA_DIRdataDatenbank, Cover, Uploads
SCAN_INTERVAL30Minuten zwischen zwei automatischen Scans
SERVER_NAMEMusikName, der in den Apps und auf Teilen-Seiten steht

Pfade im Container: Einstellungen /etc/musik.env, Daten /var/lib/musik, Musik /srv/musik, Logs journalctl -u musik -f.

04Unterwegs hören (Tailscale)

Ohne Extra-Schritte funktionieren die Apps nur zuhause im selben WLAN. Mit Tailscale gehen sie überall, auch über mobile Daten, ohne Portfreigabe und ohne dass etwas offen im Internet steht.

  1. Beim Installieren die Frage mit 2) Mit Tailscale beantworten. Bei einem bestehenden Server einfach das Proxmox-Skript noch mal ausführen.
  2. Den Link öffnen, den der Installer zeigt, und dich bei Tailscale anmelden (kostenloses Konto).
  3. Die Tailscale-App aufs Handy (und bei Bedarf auf den PC), mit demselben Konto anmelden.
  4. Musik einmal zuhause öffnen. Unterwegs wechselt die App von selbst auf die Tailscale-Adresse, z. B. https://musik.tailxxxx.ts.net.

Die Adresse für unterwegs steht auch in der App unter Einstellungen → Unterwegs. Ausführlich: docs/tailscale.md.

06Musik hinzufügen

  • Ordner: Dateien in den Musikordner legen. Der Server liest alle 30 Minuten neu ein, sofort geht es mit Einstellungen → Bibliothek neu einlesen.
  • Hochladen: Einstellungen → Musik hochladen, mehrere Dateien auf einmal.
  • Formate: MP3, FLAC, M4A/AAC, OGG, WAV, WebM. Titel, Künstler, Album, Cover und Songtexte liest der Server aus den Tags.

07Die App benutzen

Mix für dich und Radio

Mix für dich auf der Startseite ist nach deinem Geschmack sortiert. Radio ab Song (im Menü eines Songs) spielt ähnliche Songs und setzt die Warteschlange von selbst fort. Schlaues Mischen spielt Favoriten öfter und nie zweimal denselben Künstler hintereinander.

So lernt der Mix: ganz gehört zählt positiv, früh übersprungen negativ, ein Like stark positiv. Ältere Signale verlieren mit der Zeit an Gewicht (Halbwertszeit 30 Tage).

Playlists und Likes

Herz bei einem Song, um ihn zu liken (landet in Lieblingssongs). Neue Playlist über das + in der Seitenleiste oder im Menü eines Songs Zur Playlist hinzufügen. Reihenfolge per Ziehen ändern.

Vollbild-Player

Auf dem Handy auf den kleinen Player tippen, am PC auf das Cover. Dort findest du Visualizer, Songtext und die Warteschlange.

Playlists importieren

Bibliothek → Importiert → Importieren, Link einfügen oder Datei wählen, Namen prüfen, Importieren. Jeder Song wird mit deiner Bibliothek abgeglichen (Titel, Künstler, Länge). Treffer spielen lokal, der Rest über die Plattform. Ausgeschaltete Plattformen werden grau angezeigt und übersprungen. Mit Als Playlist speichern wird aus den lokalen Treffern eine normale Playlist.

Spotify verbinden

  1. Auf developer.spotify.com eine App anlegen und Web API sowie Web Playback SDK anhaken.
  2. Als Redirect URI die Adresse eintragen, die Musik unter Quellen → Spotify zeigt. Spotify verlangt https, nimm also die Tailscale-Adresse.
  3. Client-ID in Musik einfügen, Mit Spotify verbinden. Alternativ einen Token einfügen.
Spotify-Regeln seit Februar 2026: Der Besitzer der Entwickler-App braucht Premium, höchstens 5 Nutzer, und Inhalte gibt es nur für eigene oder gemeinsame Playlists. Fremde Playlists vorher in die eigene Bibliothek kopieren oder per Exportify als CSV importieren.

YouTube-Schlüssel (optional)

Ohne Schlüssel liest Musik Playlists über den eingebetteten Player. Mit einem Schlüssel (Google Cloud, YouTube Data API v3) gibt es genauere Titel und die Suche nach YouTube-Songs. Eintragen unter Quellen → YouTube.

Musik nutzt nur die offiziellen Player und Schnittstellen der Plattformen. Es wird nichts heruntergeladen oder mitgeschnitten. Der YouTube- und SoundCloud-Player bleibt deshalb sichtbar, als kleines Fenster oder im Vollbild über dem Cover.

09Teilen

Bei Songs, Alben und Playlists auf Teilen tippen. Auf dem Handy öffnet sich das Teilen-Menü, am PC wird der Link kopiert. Der Link /s/… öffnet eine eigene Seite: Jeder kann dort reinhören, auch ohne Konto. Wer im selben Browser angemeldet ist, speichert die Playlist mit In meiner Bibliothek speichern.

Damit Freunde den Link von außerhalb öffnen können, muss dein Server für sie erreichbar sein, zum Beispiel über Tailscale (gleiches Tailnet oder Tailscale Funnel) oder eine eigene Domain.

10Equalizer, Visualizer, Songtexte

Equalizer

Einstellungen → Equalizer: 10 Bänder von 31 Hz bis 16 kHz, Vorverstärkung und Presets (Neutral, Mehr Bass, Mehr Höhen, Stimme, Akustik, Elektronisch, Nachts leise). Im Browser und am PC über WebAudio, auf Android über den System-Equalizer. Songs von YouTube, SoundCloud und Spotify lassen sich nicht verändern.

Visualizer

Im Vollbild-Player auf Visualizer tippen. Jeder Tipp schaltet weiter: Balken, Kreis (strahlt ums Cover, das im Takt pulsiert), Welle, aus. Am PC gibt es dafür auch einen Knopf in der Player-Leiste. Die Farben kommen aus dem Cover. Den Stil kannst du auch unter Einstellungen → Visualizer wählen.

Android fragt einmal nach der Berechtigung „Audio aufnehmen“. Die braucht Android für jeden Visualizer, es wird nichts aufgenommen. Bei Songs von Plattformen gibt es keinen Zugriff auf den Ton, dort läuft eine ruhige Deko-Animation.

Songtexte

Knopf Songtext im Player. Zuerst wird der Text aus der Datei gelesen, sonst von LRCLIB geholt (kostenlos). Synchrone Texte laufen mit, ein Tipp auf eine Zeile springt an die Stelle.

11Konten und Einstellungen

  • Mehrere Leute: Der erste Account ist Admin und legt unter Einstellungen → Nutzer weitere an. Jeder hat eigene Playlists, Likes und einen eigenen Mix.
  • Aussehen: Sprache Deutsch/Englisch, Akzentfarbe Blau, Grün oder Lila, oder Farben aus dem Cover.
  • Passwort ändern und abmelden unter Einstellungen → Konto.

12Updates und Sicherung

  • Server: Proxmox-Skript erneut ausführen oder musik-update. Docker: git pull && docker compose up -d --build.
  • Apps: neue Version von der Release-Seite drüber installieren.
  • Sicherung: Es reicht der Datenordner (/var/lib/musik bzw. data/). Darin liegen Datenbank, Cover und hochgeladene Songs. Am einfachsten über das Proxmox-Backup des Containers.

13Wenn etwas nicht klappt

Die App findet den Server nicht

Adresse mit Port prüfen (:8484), Handy im selben WLAN? Im Browser http://ADRESSE:8484/api/info öffnen, dort muss "app":"musik" stehen. Im Container: systemctl status musik.

Neue Songs tauchen nicht auf

Bibliothek neu einlesen drücken. Liegt die Musik auf dem Host, prüfen, ob MUSIC_HOST_DIR gesetzt war und der Ordner lesbar ist.

Unterwegs geht nichts

Tailscale-App auf dem Handy an und mit demselben Konto angemeldet? Im Container tailscale status. Die Adresse steht unter Einstellungen → Unterwegs.

Spotify spielt nicht

Im Browser braucht es Premium und einen Browser mit DRM. Sonst Spotify auf einem anderen Gerät öffnen, Musik steuert es dann über Spotify Connect. Redirect URI muss genau der angezeigten Adresse entsprechen.

Ein YouTube-Video wird übersprungen

Manche Videos dürfen nicht eingebettet werden. Musik springt dann zum nächsten Song.

Logs ansehen

journalctl -u musik -f

Fehler oder Ideen gerne als Issue auf GitHub.

01Overview

Musik has three parts:

  • Server: a small program (Rust) that reads your music files, remembers what you listen to and streams everything to the apps. Best as a container in Proxmox, but Debian, Ubuntu, Docker, Windows and a Raspberry Pi work too.
  • Apps: Android, Windows and Linux, plus the web player served by the server itself.
  • The mix: a recommendation engine on your server. It learns from what you play through, skip and like.

Your files stay on your server. Other platforms (YouTube, Spotify, SoundCloud) only join in when you switch them on.

02Quick start

  1. Install the server, easiest in Proxmox (see Install). At the end you get an address like http://192.168.1.50:8484.
  2. Open that address in a browser or enter it in the app. On first start you create your account; the first one is admin.
  3. The app asks where songs may come from. “Local” is enough to begin.
  4. Put music into the music folder or upload it in the app under Settings → Upload music.
  5. Tap Home and play “Your mix”.

You can also reach the web player with the Web player button at the top right of the home page. It remembers your server address.

03Install the server

Proxmox (recommended)

In Proxmox click the node, open Shell and paste:

bash -c "$(curl -fsSL https://raw.githubusercontent.com/Labtoso/Musik/main/deploy/proxmox.sh)"

The script creates a Debian 12 container (2 cores, 512 MB RAM, 8 GB), installs the server and prints the address. It asks once whether you want Musik with or without Tailscale (see On the go).

Put options in front of the command, for example MUSIC_HOST_DIR=/mnt/nas/music bash -c "…":

OptionMeaning
MUSIC_HOST_DIRFolder on the Proxmox host with your music, mounted read-only into the container (/srv/musik/library).
CTIDContainer number, otherwise the next free one.
CT_CORES, CT_RAM, CT_DISKCores, RAM in MB, disk in GB (default 2 / 512 / 8).
CT_BRIDGE, CT_STORAGENetwork bridge (default vmbr0) and storage for the container.
TAILSCALE=1 / TAILSCALE=0Tailscale on or off without asking.

Update: run the same command again. The script finds the container and updates it. Data, playlists and likes stay.

Debian / Ubuntu

Installs the musik service (systemd). Options after bash -s --: --music /path, --port 8484, --tailscale, --no-tailscale, --ts-authkey …. Update later with musik-update.

Docker

git clone https://github.com/Labtoso/Musik.git && cd Musik && docker compose up -d --build

Music goes into music/ next to docker-compose.yml, data lives in data/. Port 8484.

Windows

Download musik-server-windows-x64.exe from the release page and run it. It uses your Music folder. Other folders go into a .env next to the exe: MUSIC_DIRS=D:\Music.

Server settings

The server reads environment variables or a .env file. In the Proxmox container and on Debian it is /etc/musik.env. After a change: systemctl restart musik.

04On the go (Tailscale)

Without extra steps the apps only work at home on the same Wi-Fi. With Tailscale they work anywhere, also on mobile data, with no port forwarding and nothing open to the internet.

  1. Answer the installer question with 2) With Tailscale. For an existing server just run the Proxmox script again.
  2. Open the link the installer shows and log in to Tailscale (free account).
  3. Install the Tailscale app on your phone (and PC if you like) with the same account.
  4. Open Musik once at home. Away from home the app switches to the Tailscale address by itself, e.g. https://musik.tailxxxx.ts.net.

The on-the-go address is also in the app under Settings → On the go. Full guide (German): docs/tailscale.md.

06Add music

  • Folder: put files into the music folder. The server rescans every 30 minutes, or right away with Settings → Rescan library.
  • Upload: Settings → Upload music, several files at once.
  • Formats: MP3, FLAC, M4A/AAC, OGG, WAV, WebM. Title, artist, album, cover and lyrics come from the tags.

07Using the app

Your mix and radio

Your mix on the home page is sorted by your taste. Radio from song (in a song’s menu) plays similar songs and keeps the queue going. Smart shuffle plays favourites more often and never the same artist twice in a row.

How the mix learns: playing through counts positive, an early skip negative, a like strongly positive. Older signals fade over time (half-life 30 days).

Playlists and likes

Tap the heart to like a song (it lands in Liked songs). New playlist with the + in the sidebar, or Add to playlist in a song’s menu. Drag to reorder.

Full screen player

On the phone tap the mini player, on the PC the cover. There you find Visualizer, Lyrics and the Queue.

08Other platforms

On first start (and later under Settings → Sources) you choose where songs may come from.

SourceImportPlayback

Import playlists

Library → Imported → Import, paste a link or pick a file, check the name, Import. Every song is matched against your library (title, artist, length). Matches play locally, the rest through the platform. Platforms that are switched off are greyed out and skipped. Save as playlist turns the local matches into a normal playlist.

Connect Spotify

  1. On developer.spotify.com create an app and tick Web API and Web Playback SDK.
  2. As redirect URI enter the address Musik shows under Sources → Spotify. Spotify requires https, so use the Tailscale address.
  3. Paste the client ID into Musik and press Connect Spotify. Or paste a token.
Spotify rules since February 2026: the developer app owner needs Premium, at most 5 users, and contents only for own or collaborative playlists. Copy other playlists into your library first, or import them as CSV via Exportify.

YouTube key (optional)

Without a key Musik reads playlists through the embedded player. With a key (Google Cloud, YouTube Data API v3) you get more accurate titles and YouTube search. Enter it under Sources → YouTube.

Musik only uses the platforms’ official players and APIs. Nothing is downloaded or recorded. That is why the YouTube and SoundCloud player stays visible, as a small window or over the cover in full screen.

09Sharing

Tap Share on songs, albums and playlists. On the phone the share sheet opens, on the PC the link is copied. The /s/… link opens its own page: anyone can listen there, even without an account. Anyone signed in in the same browser saves the playlist with Save to my library.

For friends to open the link from outside, your server has to be reachable for them, for example via Tailscale (same tailnet or Tailscale Funnel) or your own domain.

10Equalizer, visualizer, lyrics

Equalizer

Settings → Equalizer: 10 bands from 31 Hz to 16 kHz, preamp and presets (Flat, Bass boost, Treble boost, Vocal, Acoustic, Electronic, Night). WebAudio in the browser and on the PC, the system equalizer on Android. Songs from YouTube, SoundCloud and Spotify cannot be changed.

Visualizer

In the full screen player tap Visualizer. Each tap moves on: Bars, Ring (radiates around the cover, which pulses with the beat), Wave, off. On the PC there is also a button in the player bar. Colours come from the cover. You can also pick the style under Settings → Visualizer.

Android asks once for the “record audio” permission. Android needs it for any visualizer; nothing is recorded. Platform songs give no access to their sound, so a calm decorative motion runs instead.

Lyrics

Lyrics button in the player. First from the file’s tags, otherwise from LRCLIB (free). Synced lyrics follow along; tap a line to jump there.

11Accounts and settings

  • Several people: the first account is admin and adds others under Settings → Users. Everyone gets their own playlists, likes and mix.
  • Look: German or English, accent blue, green or purple, or colours from the cover.
  • Change password and sign out under Settings → Account.

12Updates and backup

  • Server: run the Proxmox script again or musik-update. Docker: git pull && docker compose up -d --build.
  • Apps: install the new version from the release page over the old one.
  • Backup: the data folder is enough (/var/lib/musik or data/): database, covers and uploaded songs. Easiest with a Proxmox backup of the container.

13When something does not work

The app cannot find the server

Check the address with port (:8484), is the phone on the same Wi-Fi? Open http://ADDRESS:8484/api/info in a browser, it must show "app":"musik". In the container: systemctl status musik.

New songs do not show up

Press Rescan library. If the music is on the host, check that MUSIC_HOST_DIR was set and the folder is readable.

Nothing works on the go

Is the Tailscale app on and signed in with the same account? In the container run tailscale status. The address is under Settings → On the go.

Spotify does not play

In the browser you need Premium and a browser with DRM. Otherwise open Spotify on another device and Musik controls it via Spotify Connect. The redirect URI must match the shown address exactly.

A YouTube video gets skipped

Some videos may not be embedded. Musik then moves on to the next song.

Read the logs

journalctl -u musik -f

Bugs or ideas are welcome as an issue on GitHub.
